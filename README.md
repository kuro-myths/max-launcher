## 🎯 Rencana

Max Launcher terinspirasi oleh konsep [craft-launcher](https://github.com/storytold/craft-launcher)
(lisensi MIT OR Apache-2.0): satu aplikasi untuk meng-install, meng-update, dan membuka seluruh suite
aplikasi. Tujuan jangka panjang Max Launcher adalah hal serupa untuk ekosistem Max, dibangun dengan
**Rust**, dengan branding dan kode milik sendiri.
